# NetworkCompat

NetworkCompat is an experimental NeoForge mod for attempting connections between modded clients and servers whose
installed mods or network registrations do not fully match. It relaxes selected compatibility checks; it does not
install missing mods or guarantee that either side can safely use content it does not have.

## Warning

**After installing NetworkCompat, other mods may not work as intended. Connections may cause missing content, protocol
errors, data loss, unexpected behavior, or crashes. Compatibility is not guaranteed.**

**Do not report a crash to another mod's author while NetworkCompat is installed. First reproduce the issue without
NetworkCompat, using the same game version, loader, and other mods. If the crash only occurs with NetworkCompat
installed, report it to the NetworkCompat maintainers instead.**

> Use this mod only when you understand the risks, and keep backups of important worlds.

## Features

- Attempts to let a modded client connect to a vanilla server when the client-side unsafe option permits it.
- Can let a NeoForge server continue network negotiation when the client advertises channels that the server does not
  have. Missing server channels are reported to the client; the server cannot provide the absent handlers or mod
  content.
- Allows selected registry and extensible-enum compatibility checks to be bypassed when unsafe mode is enabled.
- Supports a configurable client virtual hostname, useful with proxy software such as Velocity when routing by forced
  host.
- Disable creative items that not exists in server.

These changes bypass checks; they do not make different mod lists, registries, or protocol versions equivalent. The
server can still reject a connection, and a connection that succeeds can still be unstable or unplayable.

## Requirements

- Minecraft 1.21.1
- NeoForge for Minecraft 1.21.1

Install the matching NetworkCompat build in the client or server instance where its features are needed. For a
modded-client-to-vanilla-server connection, install it on the client. For a NeoForge server to accept clients with extra
network channels, install it on the server. Install it on both sides if you need both sets of behavior.

## Configuration

Configuration files are generated by NeoForge after the corresponding side starts.

### Client

The client config is available from the Mods screen and is stored in `config/networkcompat-client.toml`.

| Option         | Default                   | Description                                                                                                                                                                             |
|----------------|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `unsafe`       | `true`                    | Allows selected unsafe compatibility paths, including attempts to connect to vanilla servers and bypasses for registry or extensible-enum mismatches. Disable it to reject those cases. |
| `client-vhost` | `test-router.example.com` | Hostname sent in the client's handshake. Set this to the hostname expected by your proxy's forced-host routing, or change it to the value appropriate for your setup.                   |

### Server

The server config is stored in `world/serverconfig/networkcompat-server.toml`.

| Option         | Default | Description                                                                                                                                            |
|----------------|---------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| `allow-unsafe` | `true`  | Allows negotiation to continue when a client advertises network channels absent from the server. This does not supply those channels' implementations. |

Changing these options does not make an unsafe connection safe. For the most reliable result, use matching Minecraft,
NeoForge, and mod versions on both sides.

## Troubleshooting

1. Confirm that Minecraft and NeoForge versions match the NetworkCompat build.
2. For ordinary play, first try matching the client and server mod lists and versions.
3. If a crash occurs, remove NetworkCompat and reproduce it before contacting another mod's author.
4. If the issue requires NetworkCompat, include the client and server logs, exact mod lists, and the relevant config
   values when reporting it to NetworkCompat maintainers.

## Development

This project uses Gradle and NeoForge ModDevGradle. Open the project in an IDE with Java 21 support. The configured
development runs are `client`, `server`, `gameTestServer`, and `data`.
